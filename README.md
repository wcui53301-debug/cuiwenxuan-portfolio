# 崔文轩个人作品集

在线访问：https://www.cuiwenxuan.space/

本仓库为个人作品集静态网站备份，保留完整图片、字体、交互及作品链接。

## 本地预览

在仓库目录运行 `python3 -m http.server 4319`，浏览器访问 `http://localhost:4319/`。

## 部署

静态站点，无需构建。部署根目录为仓库根目录，入口为 `index.html`。

- `assets/`：人物、纸张和界面素材
- `works/`：作品图片
- `fonts/`：思源宋体及许可证
- `outline-assets/`：封面素材
- `works.js`、`work-assets.js`：项目文案、排版与图片链接
